\# Jobsy – Job Platform



A full-stack job platform connecting students and employers, featuring job 

listings, applications, and user profiles. Built with a Java backend and a 

React frontend.



\## Tech Stack

\*\*Backend\*\*

\- Java

\- DAO pattern for data persistence

\- File-based storage



\*\*Frontend\*\*

\- React

\- Tailwind CSS



\## Features

\- Job listings and job details

\- Post job / apply to job flows

\- User authentication (login/signup)

\- Student and employer profiles

\- Landing page and navigation

\## How to Run



\*\*Backend:\*\*

1\. Navigate to `jobsy-backend`

2\. Run: `mvn spring-boot:run` (or via `mvnw` if Maven isn't installed globally)



\*\*Frontend:\*\*

1\. Navigate to `jobsy-frontend`

2\. Run: `npm install`

3\. Run: `npm start`
